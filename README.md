# Smart Campus Resource & Room Booking System — Prototype

A polished React + Vite prototype for a campus resource booking workflow.

## Run
npm install
npm run dev

## Build for deployment
npm run build

The prototype uses localStorage for booking state, so it can be deployed as a static site. No database/backend is required for the prototype.

## Deploy on Vercel
1. Push this folder to GitHub.
2. Import the repository into Vercel.
3. Framework preset: Vite.
4. Build command: `npm run build`
5. Output directory: `dist`
